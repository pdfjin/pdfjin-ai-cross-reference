Fast, private, and local document processing with zero size limits.

> 🌐 **Prefer a Web UI?** Use the free online browser tool at **[https://pdfjin.com/pages/ai-cross-reference.html](https://pdfjin.com/pages/ai-cross-reference.html)**.

---

## 📦 Installation

```bash
pip install pdfjin-ai-cross-reference
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-ai-cross-reference.git
cd pdfjin-ai-cross-reference
pip install .
```

---

## 🚀 Quickstart

Run via CLI:
```bash
pdfjin-ai-cross-reference --help
```

Use in Python:
```python
import pdfjin_ai_cross_reference
```
